# Bouncy Jump

> **Proprietary & confidential.** © 2026 Uğur Günal / Rugu Studios. All rights reserved.  
> Not open source. Do not copy, redistribute, or reuse any code or assets. See [LICENSE](LICENSE).

A casual mobile tower-jumping game built with Unity. Climb as high as you can, collect diamonds, unlock balls, and keep bouncing.

**Official package / bundle ID:** `com.rugustudios.bouncyjump`  
Releasing on **Google Play** and the **App Store** (pending review).

## Features

- Endless vertical jump gameplay
- Multiple unlockable balls
- Diamond shop with rewarded ads and in-app purchases
- Android and iOS builds

## Tech

| | |
|---|---|
| Engine | Unity **2022.3.62f2** (LTS) |
| Platforms | Android, iOS |
| Package ID | `com.rugustudios.bouncyjump` |
| Ads | Unity Ads (rewarded) |
| IAP | Unity IAP (gem packs) |
